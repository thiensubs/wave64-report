The RX 580 Metal port

Two patches that put Stable Diffusion 2.1 on an AMD RX 580. Apply them on top of a clean upstream checkout.

Patch it in one go

Get the bundle from the repo, then run the helper from inside your checkout:

git clone https://github.com/thiensubs/wave64-report
git clone https://github.com/leejet/stable-diffusion.cpp
cd stable-diffusion.cpp
git checkout 5356982
git submodule update --init --recursive
bash ../wave64-report/sd-cpp/apply.sh .

No downloads, no installs: the helper runs git apply on the two patch files next to it. Read it first — that is the point. Manual steps are below if you prefer them.

Apply

git clone https://github.com/leejet/stable-diffusion.cpp
cd stable-diffusion.cpp
git checkout 5356982
git submodule update --init --recursive

git apply /path/to/0002-group-norm-inplace.patch

cd ggml
git apply /path/to/0001-ggml-metal-rx580.patch
cd ..

0001 applies inside ggml/ because its paths are relative to that submodule.

Build (Mac with Metal)

cmake -B build -DGGML_METAL=ON -DCMAKE_BUILD_TYPE=Release
cmake --build build --target sd-cli test-backend-ops -j8

Stale kernels. The build copies kernels/*.metal into build/bin/kernels/. Edit a kernel without rebuilding and you are running the old one — a silent no-op on this port.
